# EcoReport Core Beliefs

## Mission

EcoReport의 목적은 리포트를 많이 쌓는 것이 아니라, 리포트와 포트폴리오 상태를 연결해 실제 계좌 액션 비용을 낮추는 것입니다.

## Non-Negotiable Beliefs

1. 리포트 요약보다 계좌 의사결정 번역이 더 중요하다.
2. 강한 액션은 항상 근거 링크를 가져야 한다.
3. 직접 종목 언급이 없으면 먼저 자산군/테마/계좌 레벨로 해석한다.
4. 단일 리포트의 강한 어조보다 반복적으로 생존하는 논리를 더 신뢰한다.
5. Stage 2는 해석 엔진이지만 source-of-truth는 아니다.
6. Stage 3/4는 재현 가능하고 설명 가능해야 한다.
7. 좋은 해석은 채팅에서 끝내지 말고 문서나 위키로 되돌려야 한다.

## Translation Hierarchy

리포트를 아래 순서로 번역합니다.

1. `macro event`
2. `asset class / theme`
3. `account relevance`
4. `ticker / holding`
5. `execution action`

직접 종목 커버 리포트가 아니라면, 처음부터 개별 종목 매수/매도 액션으로 점프하지 않습니다.

## What Counts As Good Evidence

- Stage 1 `key_thesis`, `key_points`, `key_numbers`, `portfolio_impacts_candidate`
- Impact Map의 `direction`, `magnitude`, `account_relevance`, `rationale`
- Stage 2의 `holdings_bias`, `sector_bias`, `new_candidates`
- Stage 3의 `reportImpacts`, `coverage`, `signal`
- Stage 4의 `stage1Drivers`, `macroCommentary.actionLine`

## What To Avoid

- 리포트에 없는 단정적 서사 추가
- 근거 없이 계좌 전체 성격 바꾸기
- mock 결과를 실제 판단처럼 숨기기
- `impact-map`이 비어 있는데도 강한 실행 계획 생성
- 위키나 문서에 남기지 않는 일회성 판단

## Default Decision Style

- 확신이 낮으면 공격적 매수보다 `WATCH` 또는 `HOLD`
- 매크로 불확실성이 크면 성장주 단일 종목보다 ETF/현금/헤지 해석 우선
- 동일 방향 리포트가 여러 개 누적될 때 conviction을 올림
- 포트폴리오 데이터가 불완전하면 신호보다 데이터 품질 경고를 우선 노출
