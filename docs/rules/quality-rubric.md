# EcoReport Quality Rubric

일일 산출물과 에이전트 변경을 아래 5개 축으로 평가합니다.

각 항목은 `0~3점`으로 봅니다.

## 1. Evidence Quality

- `0`: 주장만 있고 근거가 거의 없음
- `1`: 리포트 인용은 있지만 계좌 연결이 약함
- `2`: 리포트, technical, portfolio 중 2개 이상 연결됨
- `3`: 근거, 숫자, 반증 조건이 모두 명시됨

## 2. Portfolio Translation

- `0`: 리포트 요약만 있고 계좌 액션이 없음
- `1`: 계좌 언급은 있으나 이유가 약함
- `2`: 계좌/카테고리/종목 연결이 대부분 설명됨
- `3`: 왜 이 계좌에서 이 액션인지 명확하고 재사용 가능함

## 3. Actionability

- `0`: 실행 문장이 없음
- `1`: 실행 문장이 추상적임
- `2`: staged buy, hold, watch 구분이 읽힘
- `3`: 금액/우선순위/보류 조건이 모두 읽힘

## 4. Uncertainty Handling

- `0`: 확신 없는 상태를 숨김
- `1`: 불확실성을 언급하지만 영향은 반영 안 함
- `2`: mock, missing coverage, incomplete snapshot을 드러냄
- `3`: 불확실성을 점수와 액션에 실제로 반영함

## 5. Memory Writeback

- `0`: 좋은 해석이 채팅에서 사라짐
- `1`: 일일 보고서에는 남지만 장기 기억에는 안 남음
- `2`: 위키 또는 문서에 일부 반영됨
- `3`: 위키, 규칙, playbook 중 적절한 위치로 되돌려짐

## Minimum Bar

운영 기준 최소선:

- Evidence Quality: `2`
- Portfolio Translation: `2`
- Actionability: `2`
- Uncertainty Handling: `2`

이 중 하나라도 `1` 이하라면 "생성됨"과 "쓸 만함"을 구분해서 봐야 합니다.
