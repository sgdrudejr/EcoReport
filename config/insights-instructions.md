# 인사이트 파이프라인 작업지침서

이 파일은 깃으로 관리되며, `run_insights_pipeline.py`가 실행될 때 자동으로 읽혀
LLM 프롬프트에 주입됩니다. 분석 방향을 바꾸고 싶으면 이 파일만 수정하고 커밋하면 됩니다.

---

## 포트폴리오 컨텍스트

- 투자 성향: 3~6개월 ETF 중심, fundamental + technical 혼합
- 주요 관심 계좌: ISA / PENSION / KIS_MAIN
- 관심 섹터: 반도체, 방산, 원자력, 미국 S&P500, 나스닥, 배당

## 분석 우선순위

1. **매크로 레짐 판단** — 현재 Growth / Stagflation / Risk-Off 중 어디?
2. **크로스카테고리 신호** — 채권+매크로+전략 리포트가 같은 방향을 가리키는가?
3. **컨센서스 vs 소수의견** — 80% 이상 동의하는 테마와, 그에 반하는 소수 논리
4. **종목 모순 탐지** — 같은 종목에 대해 매수/매도가 동시에 나오는 경우 근거 비교
5. **실행 가능한 아이디어** — ETF 또는 개별 종목 기준, 진입 근거와 리스크 포함

## 딥리서치 요청 시 강조할 점

- 한국 시장(KOSPI/KOSDAQ) 중심이지만 글로벌 매크로와 연결
- 단기(1개월) 실행 가능성을 최우선으로 판단
- 불확실성이 높은 항목은 "관망" 또는 "분할 접근" 권고

## 제외할 내용

- 이미 편출한 종목에 대한 재진입 추천은 무시
- 레버리지/인버스 ETF 추천은 제외

## Qwen 딥리서치 설정 (provider: qwen)

### 분석 모델
- **기본 모델**: `qwen-max` (DashScope API)
- **엔드포인트**: `https://dashscope.aliyuncs.com/compatible-mode/v1`
- **web_search 툴**: 활성화 — 실시간 뉴스/데이터 교차 검증에 사용

### CoT (Chain-of-Thought) 추론 순서
모든 LLM 호출에 자동 주입됨:
1. 핵심 키워드 3개 분해
2. 각 키워드별 Bullish / Bearish 양면 검토
3. 수집 정보 간 모순 탐지 및 논리적 해결
4. 실행 가능한(actionable) 인사이트 도출

### 에이전트 워크플로우 (딥리서치 모드)
```
Plan  → Qwen이 무엇을 검색/조사할지 계획 수립
Search → web_search 툴로 실시간 뉴스/지표 검색
Analyze → 충분한 정보인지 검토 (부족 시 Plan으로 재순환)
Draft → 모든 정보 취합 → 최종 리포트 작성
```

### 교차 검증 명령어 (Step 0 분석 시 활용)
```
"리포트 요약(JSON)의 지표들이 현재 실시간 뉴스 매크로 상황과 일치하는지
교차 검증하고, 괴리가 있다면 그 이유를 심층 분석하라."
```
